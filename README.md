# 🔢 PyQt5 Semi-Prime Checker

A simple desktop application built with **Python** and **PyQt5** to determine whether a number is **semi-prime**.

A **semi-prime number** is a natural number that is the product of **two prime numbers** (they may be the same).

## ✨ Features

* 🔍 Check if a number is semi-prime
* ✅ Prime number verification
* 🧠 Integer square root optimization
* ⚡ Fast and lightweight interface
* 🖥️ User-friendly GUI built with Qt Designer

## 📖 How to Use

1. Enter a number greater than **2**.
2. Click the **Verify** button.
3. The application checks whether the number is semi-prime.
4. The result is displayed instantly.

## 💡 Examples

| Number | Result               |
| ------ | -------------------- |
| 4      | ✅ Semi-prime (2 × 2) |
| 6      | ✅ Semi-prime (2 × 3) |
| 9      | ✅ Semi-prime (3 × 3) |
| 10     | ✅ Semi-prime (2 × 5) |
| 12     | ❌ Not semi-prime     |
| 17     | ❌ Prime number       |
